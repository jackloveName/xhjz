# App Store 元数据

## 应用名称

薪花记账

## 副标题

小票凭证收纳与提醒

## 宣传文本

拍下小票、报销材料、售后凭证和重要票据，设置提醒日期，打开 App 就能继续处理；完成后归档，月底查看未处理事项和月度统计。

## 应用介绍

薪花记账是一款面向日常凭证管理的轻量工具，帮你把小票、报销材料、售后凭证和重要票据有条理地收纳起来。

很多小票不是马上就会用到：有些要等报销，有些要留给售后，有些只是以后可能会查。薪花记账把这些凭证从相册和聊天记录里整理出来，让每一张凭证都有明确的去向。

你可以：

拍照或从相册上传小票、发票、售后凭证等图片；
按小票、报销、售后、重要材料等类型整理；
为需要后续处理的凭证设置 3 天、7 天、30 天或自定义提醒；
记录报销金额、处理备注和当前进度；
打开 App 时查看待处理提醒，并选择今日不提醒、不再提醒或去处理；
处理完成后一键归档，形成完整闭环；
按月查看凭证数量、图片凭证、处理率和类型分布；
月底查看未处理凭证提示，避免重要材料被遗忘。

我们重视数据安全。你的凭证图片、备注、提醒记录等重要数据会采取加密存储、传输加密和权限控制等保护措施，尽量降低数据泄露、丢失和未经授权访问的风险。

薪花记账不强调复杂报表，也不替你做专业财务判断。它更像一个安静的凭证收纳盒：把需要保存的材料放好，在该处理的时候提醒你，处理完之后安心归档。

适合这些场景：

报销小票暂时不能提交，先保存并设置提醒；
购物小票需要保留一段时间，以备售后；
发票、收据、合同附件等材料需要集中存放；
月底想快速看一眼还有哪些凭证没有处理；
不想在相册里反复翻找小票和票据图片。

如果你经常遇到“小票拍了但找不到”“报销材料忘记处理”“售后凭证过期才想起来”的情况，薪花记账可以帮你把这些琐碎事项收进一个更清楚的流程里。
