欢迎使用本应用。我们重视您的个人信息与凭证数据安全。本隐私条款说明我们如何收集、使用、存储、保护和管理您的信息。请您在使用前仔细阅读并确认理解。

一、服务提供者

本应用由 ${name} 提供服务。如您对本隐私条款或个人信息保护事项有疑问，可通过 ${email} 与我们联系。

二、我们收集的信息

为向您提供凭证收纳、提醒、处理归档、账号登录与数据同步等服务，我们可能收集以下信息：

1. 账号信息：手机号、短信验证码验证结果、登录状态、设备系统类型、应用版本等。

2. 凭证信息：您主动上传的小票、报销材料、售后凭证、重要凭证图片，以及您填写的金额、备注、凭证类型、提醒日期、处理状态等。

3. 设备与日志信息：设备品牌、系统版本、网络状态、崩溃日志、操作日志等，用于保障账号安全、排查异常和改进服务稳定性。

4. 本地缓存信息：为提升使用体验，我们可能在您的设备本地保存部分凭证草稿、提醒状态、游客模式数据和页面配置。

三、我们如何使用信息

我们仅在实现产品功能和保障安全所需的范围内使用您的信息，包括：

1. 完成手机号验证码登录、账号识别、登录状态维护；

2. 保存、展示、管理您主动上传或填写的凭证资料；

3. 根据您设置的提醒日期提示未处理凭证；

4. 统计每月凭证数量、处理率、类型分布，并生成生活提示；

5. 进行数据备份、恢复、同步和异常排查；

6. 防范账号盗用、恶意请求、异常登录等安全风险。

四、加密存储与安全保护

我们将采取合理的安全措施保护您的数据。对于账号凭证、登录令牌、凭证图片、备注、提醒记录等重要数据，我们会采用加密存储、访问权限控制、传输加密、日志脱敏等方式降低泄露、篡改、丢失和未经授权访问的风险。

在本地设备中保存的数据，我们会尽量采用系统安全存储能力或加密缓存方式处理；在服务器端保存的数据，我们会根据数据敏感程度采取加密存储、权限隔离、备份保护等措施。

请您理解，互联网环境不存在绝对安全。我们会持续改进安全能力，但也建议您妥善保管手机、验证码、账号密码及设备解锁信息。

五、权限调用说明

在使用过程中，我们可能向您申请以下权限。您可以选择是否授权，拒绝授权可能导致对应功能无法使用，但不影响其他基础功能。

1. 相机权限：用于拍摄小票、发票、售后凭证等图片。

2. 相册权限：用于从相册选择凭证图片或保存相关图片。

3. 通知权限：用于提醒您处理未完成凭证或月底未归档事项。

4. 网络权限：用于登录、同步数据、上传凭证图片和检查版本更新。

六、我们如何共享、转让、公开披露信息

我们不会出售您的个人信息。除以下情形外，我们不会向第三方共享、转让或公开披露您的个人信息：

1. 已获得您的明确同意；

2. 为实现登录验证、云端存储、图片上传、消息提醒、故障排查等必要服务，由受托服务商在约定范围内处理；

3. 根据法律法规、司法机关或行政机关依法提出的要求；

4. 为保护用户、我们或公众的人身财产安全、账号安全和合法权益所必需。

七、信息保存期限

我们仅在实现本条款所述目的所需的最短期限内保存您的信息。您删除凭证、注销账号或我们停止提供服务后，我们将根据法律法规要求删除或匿名化处理相关信息。法律法规另有规定的，从其规定。

八、您的权利

您可以通过应用内功能或联系我们行使以下权利：

1. 查看、更正、补充您的账号资料和凭证信息；

2. 删除您上传的凭证图片、备注和提醒记录；

3. 关闭或调整提醒设置；

4. 撤回已授权的系统权限；

5. 申请注销账号并删除或匿名化相关数据；

6. 对个人信息处理规则提出疑问、投诉或建议。

九、未成年人保护

本应用主要面向具备完全民事行为能力的用户。如果您是未成年人，请在监护人同意和指导下使用本应用。我们不会主动面向未成年人收集超出服务必要范围的信息。
